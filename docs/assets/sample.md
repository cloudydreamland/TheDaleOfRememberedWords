# 智能音箱设置指南

## 开箱与联网

首次开机后，指示灯变为橙色，表示设备进入配网模式。请确保手机连接 2.4GHz Wi-Fi——5GHz 频段暂不支持配网（固件版本低于 3.14 时尤其如此）。

> 常见问题：指示灯闪烁红色怎么办？
> 长按顶部静音键 8 秒恢复出厂设置，再重新配网。

## 语音指令

唤醒词默认为"小梦小梦"。你可以说：

- "小梦小梦，今天天气怎么样？"
- "小梦小梦，播放周杰伦的歌。"

固件升级包可从 https://example.com/support/download 获取，升级过程中请保持电源稳定。升级完成后版本号应显示为 v2.1.7 或更高。
